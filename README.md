# 🏦 Banking Information System (Core Java)

## 📌 Overview
This project is a prototype of a Banking Information System developed using Core Java. It demonstrates the basic functionalities of a real-world banking system, allowing users to perform operations like account creation, deposits, withdrawals, fund transfers, and viewing transaction history.

---

## 🚀 Features

- 🔐 User Registration & Login (Password Protected)
- 💳 Account Management System
- 💰 Deposit & Withdrawal Functionality
- 🔄 Fund Transfer Between Accounts
- 📊 Transaction History (Account Statements)
- ⚠️ Error Handling (Insufficient Balance, Invalid Input)
- 🧠 In-Memory Data Storage (using HashMap & ArrayList)

---

## 🛠️ Technologies Used

- Java (Core Java)
- OOP Concepts
- Collections Framework (HashMap, ArrayList)
- Console-Based Interface
